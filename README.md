# s21_containers

мини-библиотека стандартных контейнеров C++20 (`list`, `vector`, `map`, `set`, `stack`, `queue`) с итераторами, полностью шаблонная и реализованная без использования STL контейнеров.

## особенности
- полная реализация стандартных методов контейнеров.
- поддержка итераторов `begin()`/`end()` и операций `->`, `*`, `++`, `--`.
- методы проверки наполненности и изменения контейнера (`push`, `pop`, `insert`, `erase`, `clear` и др.).
- расширенные методы `insert_many` для пакетного добавления элементов.
- шаблонная архитектура, все классы внутри пространства имен `s21`.

## Makefile цели
- `all` — сборка библиотеки, тестов и примера.
- `test` — компиляция тестов.
- `run_test` — запуск тестов с выводом результатов.
- `gcov_report` — генерация отчета покрытия.
- `valgrind_test` — проверка утечек памяти.
- `clean` — очистка сборки.

## пример использования
```cpp
#include "s21_containers.h"

int main() {
    s21::vector<int> v;
    v.push_back(1);
    v.push_back(2);
    for (auto it = v.begin(); it != v.end(); ++it) {
        std::cout << *it << " ";
    }
}
````
